# SecretPowers

Paper 1.21.11 plugin: every player gets a secret random power. Preparation phase, final countdown, then the SMP goes live.

Build: push to GitHub (Actions builds it, JAR is under the run's Artifacts) or run `gradle build` locally. JAR ends up in `build/libs`.
Permissions are plain Bukkit nodes, so LuckPerms works: grant `secretpowers.admin` to your admin group.
